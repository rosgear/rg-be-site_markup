## <img src="https://raw.githubusercontent.com/rosgear/rg-be-site_markup/refs/heads/main/assets/images/icon.svg" width="64px" height="64px" align="absmiddle"> Модуль «Визуальный редактор»

Модуль входит в состав Панели управления GePanel.

Модуль предназначен для управления компонентами сайта посредством визуального редактора, включая их добавление, настройку параметров и размещение на веб‑страницах.

### Установка

Для добавления модуля в ваш проект, вы можете просто выполнить команду ниже:

```
$ composer require rosgear/rg-be-site_markup
```

или добавить в файл composer.json вашего проекта:
```
"require": {
    "rosgear/rg-be-site_markup": "*"
}
```
или скачать архив на [странице модуля](https://rosgear.ru/component/rg-be-site_markup/) в каталоге приложений RosGear.

После добавления модуля в проект выполните его установку в редакцию веб‑приложения с помощью Панели управления GePanel.

## <img src="https://raw.githubusercontent.com/rosgear/rg-be-site_markup/refs/heads/main/assets/images/icon.svg" width="64px" height="64px" align="absmiddle"> Module «Visual editor»

The module is part of the GePanel Control Panel.

The module is designed for managing website components using a visual editor, including adding them, configuring parameters, and placing them on web pages.

### Installation

To add the module to your project, you can simply run the command below:

```
$ composer require rosgear/rg-be-site_markup
```

or add to your project's composer.json file:
```
"require": {
    "rosgear/rg-be-site_markup": "*"
}
```
or download the archive from the [module page](https://rosgear.ru/component/rg-be-site_markup/) in the RosGear application catalog.

After adding the module to the project, install it into the web application edition using the GePanel Control Panel.
